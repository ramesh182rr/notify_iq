# Dark Theme Screen Reference

The full-product concept boards in `../concept_boards/` contain dark-mode dashboard, inbox, insights and rules screen examples. Use those panels together with the semantic dark tokens in `04_UI_UX_Design/DESIGN_SYSTEM.md`. Build each screen with theme-aware components rather than applying a global colour inversion.

Dark palette direction: deep navy/charcoal surfaces, soft violet accent, muted lavender secondary text, subtle borders, and restrained semantic colours. Maintain contrast and avoid neon-on-black treatment.
