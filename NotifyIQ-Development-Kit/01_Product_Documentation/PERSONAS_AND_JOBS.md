# Personas and Jobs to Be Done

## Everyday user
**Job:** “When I remember that an app notified me about something, help me find it without scrolling through every app.”
Success: fast search, simple categories, trusted privacy controls.

## Professional
**Job:** “When many work and personal alerts arrive together, help me identify which items likely need follow-up.”
Success: priority hints, saved items, daily digest, source app access.

## Power user
**Job:** “When notification patterns become noisy, let me create rules and understand which apps generate the most interruptions.”
Success: rule builder, app-level analytics, custom filters, advanced search.

## UX implications
- Onboarding must be transparent, not coercive.
- Default experience should be useful without configuration.
- Advanced controls should be discoverable but not overwhelm first-time users.
- Do not label users as “distracted” or infer sensitive traits from notification volume.
